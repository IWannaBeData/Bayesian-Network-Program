Literature review

This narrative review covers probabilistic diagnosis, inference at scale, longitudinal modeling, and how to evaluate future estimates. Sources were checked on November 21, 2026. The code inventory covers the full pinned release. The type 2 diabetes review links extracted study estimates to catalog variables.

Several diagnoses can coexist

QMR-DT modeled diseases and findings in a two-layer Bayesian network and estimated posterior disease marginals. Its companion evaluation used cases abstracted from educational material. The design is a useful starting point for representing coexisting diseases and shared findings. Evaluation in this project would need longitudinal EHR data and a reference standard for the intended setting.

Shwe et al., 1991 · Middleton et al., 1991

Graph structure controls inference cost

General exact inference is NP-hard. Dechter’s analysis shows that elimination cost grows exponentially with induced width. A sparse graph can still be difficult if it creates large intermediate factors. This favors small parent sets, limited connections between modules, and measuring inference cost for each query.

Cooper, 1990 · Dechter, 1999

Longitudinal evidence has an order

Dynamic Bayesian networks represent relationships within and across time slices. This lets the model distinguish prior disease, disease at the time of a visit, and later outcomes. Reuse chronic states across time, and give acute events an explicit window and onset.

Murphy, 2002

Population risk and visit-time diagnosis are different questions

Prospective cohort evidence links diabetes to later coronary heart disease. A visit-time acute MI model needs evidence for its presenting population, target definition, and index time. A cohort hazard ratio alone cannot fill a conditional probability table for a patient presenting today.

Emerging Risk Factors Collaboration, 2010

Diagnostic evidence depends on how it was measured

Record the study setting, patient spectrum, index test, reference standard, and missing or indeterminate results. These details determine whether a reported test likelihood can be applied in a particular care setting.

Bossuyt et al., STARD 2015

Evaluate calibration where the model will be used

Document cohort selection, predictor availability, baseline risk, missingness, and bias. Future evaluations should use separate sites and later time periods, quantify calibration and discrimination, and check performance across relevant subgroups.

Collins et al., TRIPOD+AI 2024 · Moons et al., PROBAST+AI 2025

Review and extraction

Search by diagnosis name, synonyms, and code plus type 2 diabetes. Prefer cohorts or population surveys with an explicit diabetes definition, an interpretable denominator, and a stated time window. Retain useful relative measures alongside their comparison group and report whether the paper supplies a conditional probability. The condition-level PubMed links open a reproducible starting query for further screening.

Use each estimate only for its study’s clinical definition and study population. An anatomical or severity subtype needs evidence for its own definition. An odds ratio, hazard ratio, or relative risk does not itself give either conditional probability. Check transportability and calibration before fitting a network for a different population.

Bayesian network design

At a defined index time, query P(target diagnosis in its time window | history and findings available by the index time). Start with a baseline for the cohort and care setting, then condition jointly on evidence. Report each disease marginal on its own scale so several diseases can coexist.

ICD-10-CM coding guidelines

Structure for thousands of variables

  1. Compose sparse modules. Use shared context nodes for age, encounter setting, and other supported predictors. Put established history upstream of current hypotheses and relevant findings. Keep each proposed edge reviewable with a temporal rule, a rationale, and a source. A dependency can be predictive without supporting a causal interpretation.
  2. Keep local distributions compact. Use small discrete parent sets and prefer structured conditional distributions when their assumptions fit. A noisy-OR can represent independently acting contributors. Model correlated parent effects explicitly where that assumption fails. Store nodes and edges as adjacency lists keyed by stable IDs.
  3. Compile the relevant subgraph. Validate references and acyclicity. Retain query and evidence ancestors and prune using sound conditional-independence rules so observations of shared effects can still connect hypotheses. Reuse compiled structure by network version, query scope, and evidence pattern.
  4. Budget for induced width. Estimate the largest factors under a min-fill elimination order. Use exact variable elimination or a junction tree within that budget. For larger queries, benchmark bounded approximate inference against exact results on tractable cases and expose approximation quality or return an unavailable result.
  5. Test shape and behavior independently. Exercise sparse synthetic graphs with thousands of variables, then challenge them with larger separators and shared findings. Track the largest factor, peak memory, and query latency. Verify temporal leakage, repeated evidence, and missing-data behavior on synthetic histories before any clinical evaluation.

What a future estimate must record

Capture the target variable or edge, parent states, case definition, study design, population, care setting, exposure and outcome timing, follow-up, effect measure, adjustment set, uncertainty, and DOI or PMID. Keep the source estimate and any transformation into a model parameter traceable. Estimate priors from a compatible cohort. Fit or elicit conditional distributions jointly, accounting for shared predictors and correlated evidence.
